# Personal Expense Tracker

A beginner-friendly Python project to manage daily expenses using SQLite.

## Features
- Add new expenses
- View all expenses
- Search expenses by category
- Calculate total expenses
- Store expense details permanently

## Technologies Used
- Python
- SQLite
- SQL
- VS Code

## How to Run

1. Install Python.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Run:

   python main.py
